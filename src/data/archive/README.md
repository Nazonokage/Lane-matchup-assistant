# Historical data — not used by the app

These nine files preserve the original lane guides, legacy rules, roster additions and superseded PC starter guides. They were audited and removed from the live data folder because their broad counter claims, mixed identity conditions and obsolete patch labels must not feed current suggestions.

Do not update them expecting the Draft Helper to change. See `../README.md` for the active source files. Port useful ideas only after checking the game's mechanics, role, opponent/partner direction and evidence. Historical text is reference material, not executable instructions.
